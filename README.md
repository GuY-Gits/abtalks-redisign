# ABTalks - 60-Day Coding Challenge

A mobile-first, structured 60-day coding challenge dashboard designed to help Indian college students stay consistent, ship projects, and build real skills without burning out.

**[Insert Your Vercel URL Here]**

## 💻 Tech Stack
* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS
* **Icons:** Lucide React
* **Deployment:** Vercel

## 🗺️ Route Map
* `/` - Landing Page
* `/dashboard` - Student Dashboard & Progress Tracker
* `/day/[id]` - Dynamic Daily Challenge & Proof of Work Submission

## 🛠️ Running Locally
First, install the dependencies:
\`\`\`bash
npm install
\`\`\`

Then, run the development server:
\`\`\`bash
npm run dev
\`\`\`

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
